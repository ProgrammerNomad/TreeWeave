About This Demo

This is a demonstration of TreeWeave, a free and open-source family tree visualization library. TreeWeave is framework-agnostic and works with vanilla JavaScript, React, Vue, Laravel, and more. The library uses SVG for rendering, ensuring crisp graphics on all devices and enabling easy customization through CSS.

Features showcased: Circular avatars with automatic initials fallback (when no photo is provided), level-based node coloring, responsive design, gender-specific styling, and interactive collapse/expand functionality.
